# Student Management System

A full-stack Student Management System built with React.js and Node.js.

## Features

- Admin login
- Dashboard with student statistics
- Student management
- Add student
- Edit student
- Delete student
- Search students
- Result distribution chart
- Students by class chart
- Notifications
- Responsive design for desktop, tablet, and mobile
- Protected routes
- REST API for student management

## Tech Stack

### Frontend

- React.js
- React Router
- Recharts
- Lucide React
- React Icons
- Vite
- CSS3

### Backend

- Node.js
- Express.js
- REST API

### Database

- MySQL
